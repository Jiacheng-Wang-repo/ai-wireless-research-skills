# AI + Wireless Research Skills

This repository is a focused collection of reusable skills for AI + Wireless
and computational or empirical research workflows.

## Skills

- `research-spec-loop` aligns repository authority, research lifecycle, and
  evidence state.
- `academic-writing` provides evidence-bounded scientific-writing discipline.
- `reviewer-response-writing` provides reviewer- and editor-response workflow;
  it depends on the sibling `academic-writing` skill.

## Source and installation

The canonical skill sources are the directories under `skills/` in this
repository. For user-scope Codex discovery, symlink each complete skill
directory into `~/.agents/skills/` under the same directory name. Keep
`academic-writing` and `reviewer-response-writing` installed as siblings so the
reviewer-response dependency remains valid.
